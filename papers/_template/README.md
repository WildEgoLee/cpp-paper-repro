# 论文目录模板

复制本目录为 `papers/<slug>/`，slug 用小写加年份，例如 `mimalloc-2019`。

删掉这段说明，换成下面五节：

1. 引用。作者、会议、年份、官方 PDF、官方仓库、论文实际使用的版本 tag。
2. 状态。`queued` / `protocol-frozen` / `running` / `reported` 里选一个。
3. 这篇要回答的问题。用编号 claim 写，每条附上什么样的结果算失败。
4. 第一轮跑什么，明确不跑什么。
5. 和论文机器的差异。不要把差异写成借口，写成实验设计的一部分。

在 `PROTOCOL.md` 冻结之前，不要提交结果 JSON。
